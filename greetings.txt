# =====================================================================
# JARVIS HUD - greeting corpus
# ---------------------------------------------------------------------
# One greeting per line. UTF-8, no BOM.
#
#   * Blank lines are ignored.
#   * Lines beginning with "#" are comments and are ignored.
#   * Any other line is a candidate greeting.
#
# Supported placeholders (substituted before the line is displayed):
#
#   {name}     -> the "name" value from config.txt
#   {time}     -> current local time, HH:MM
#   {date}     -> current full long date
#   {weekday}  -> current weekday name
#   {status}   -> the "status_text" value from config.txt
#
# Any other {word} is left exactly as written.
#
# A line may carry a time-of-day tag in front of it, separated by a pipe:
#
#   morning|A fine morning for it, sir.
#   afternoon|The workshop is at its brightest, sir.
#   evening|The blinds are open, sir.
#   any|Something that suits any hour.
#
# A tagged line is only ever shown during that part of the day:
#   morning   = 05:00 - 11:59
#   afternoon = 12:00 - 17:59
#   evening   = 18:00 - 04:59
#   any       = always eligible
# Untagged lines are always eligible too. If no line matches the current
# hour, the whole corpus is used instead.
#
# Keep each line under about 64 characters so that it fits the text
# column on one or two lines. A greeting is chosen at random on every
# launch, and the previous choice is not repeated when more than one
# greeting is present.
# =====================================================================
